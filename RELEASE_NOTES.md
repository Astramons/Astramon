# Astramon v0.1.0

Initial private release of Astramon.

## Highlights

- Launches the Astramon static website for `https://astramon.fun`.
- Adds the Astra-powered NFT card summon interface.
- Adds collection, market, map, bag, battle, team, and Astradex sections.
- Includes 1,934 local NFT card images.
- Adds wallet connection and live Astra balance checks.
- Adds repository documentation, issue templates, pull request template, CI, and GitHub Pages deployment.

## Production Notes

- Set `ASTRA_TOKEN_MINT` before enabling live Astra payments.
- Use Metaplex Candy Machine or another reviewed Solana mint program before selling real tradable NFTs.
