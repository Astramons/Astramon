# Changelog

All notable changes to Astramon will be documented in this file.

## [0.1.0] - 2026-05-23

### Added

- Initial private Astramon static website.
- 16-bit style dashboard, collection, battle, map, summon, and market pages.
- Astra wallet connection and live token balance reads.
- Astra token payment flow for opening card packs.
- NFT card market grid using 1,934 local card images.
- GitHub Pages deployment workflow with custom domain support.
- Private repository documentation, templates, security policy, and CI validation.
